# Security Policy

## Reporting Security Issues

We take the security and integrity of the HBB Gene Mutation Analyzer seriously.

If you believe you have discovered a vulnerability, security bug, or potential credential exposure:

1. **Do NOT open a public GitHub issue.** Public issues disclose vulnerabilities before they can be remediated.
2. Please submit a private advisory through **GitHub Private Vulnerability Reporting**:
   [Report a vulnerability](https://github.com/Manish-10275/HBB-GENE-MUTATION-PROJECT/security/advisories/new)
3. If private vulnerability reporting is unavailable, please reach out directly to the maintainer via the verified GitHub account:
   [https://github.com/Manish-10275](https://github.com/Manish-10275)

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept.
- Details of any potential secret, credential, or data exposure.

## Supported Versions

| Version | Supported          |

## Scope & Disclaimers

The HBB Gene Mutation Analyzer is designed for local-first execution on workstations for computational research and education. It does not manage or store protected health information (PHI/HIPAA) or user account databases.
